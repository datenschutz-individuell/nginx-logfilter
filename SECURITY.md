# Security Policy

What the service promises, and what it does not, is in the [threat model](doc/threat-model.md).

## Supported versions

Only the latest release is fixed. Update to it before you report.

## Reporting a vulnerability

Report a flaw that lets a client address survive, writes outside the log directory, or weakens the permissions of the nginx log directory through [**Report a vulnerability**](https://github.com/datenschutz-individuell/nginx-logfilter/security/advisories/new) on the Security tab. It stays private until a fix is published. Anything else is fine as a regular issue.

Please tell us how you want to be credited. We cannot pay a bounty.
